# Code of Conduct

Be respectful. Disagree with ideas, not people. No harassment, personal
attacks, or discriminatory language or behavior, in issues, PRs, or any
other project space.

Maintainers may remove comments, close threads, or block participants who
don't meet this bar. There's no formal enforcement ladder at this project's
current size — reports are handled directly, case by case.

To report a concern, open a private report via GitHub's "Report a vulnerability"
flow on this repo's Security tab (yes, for conduct too — it's the only
private channel this project has right now), or open a regular issue if
you're comfortable making it public.

This is a short, direct version of the same expectations the Contributor
Covenant sets out — adopted in full once the project has a large enough
community to need its formal process.
